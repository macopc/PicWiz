# PicWiz studio system

V2 direction: screenshot-first local publishing workbench. One look, several outputs; the signature is the image × format output count and inspectable export contact sheet.

Self-hosted DM Sans Variable. Studio ink #292431, desk #f6f5f8, paper #fff, pencil #746a80, hairline #e8e3ee, violet #7756dc, violet wash #f2edfd. Accent signals selection/action; status always includes text and icon.

4px spacing base. Main workspace/inspector 24/20px padding. Controls 8–12px gaps, primary 40px height, icon buttons >=32px, mobile important actions >=40px. Type: title26/600, panel15/600, body13/500, caption11/400; tabular dimensions. Subtle borders and restrained surface elevation, no ornamental card grids.

Desktop: top brand/actions, dominant canvas with adjacent annotation tools, right inspector, persistent export rail. Mobile: canvas first, explicit Style/Frame/Annotate tabs, wrapping tools, bottom export rail with content padding, dialogs fit width.

Presets: built-in versus saved, neutral rendered thumbs, apply never mutates format/content. Annotation: add→select→move/edit, visible layer list, keyboard alternatives. Batch: review sources×formats count→prepare→inspect result→download, row status and cancellation. No automatic multiple downloads.

Instant slider and annotation feedback, no decorative animation. Dialog focus behavior, visible focus, semantic live status, reduced motion. Keep helper copy readable; avoid purple-on-white low contrast for essential controls.
