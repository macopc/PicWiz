# PicWiz V2 产品设计

2026-10-23，基于 V1 的演进而非另做一个展示页。

## 设计意图

用户刚截好产品更新，几分钟后要把图片放到不同渠道。他来这里是完成发布素材，不是学习设计软件。界面应像一张干净的修图工作台：画布主导、外观一致、尺寸明确，批量状态可核对。

领域：截图、画框、留白、重点标记、发布规格、成组输出、外观配方、导出接触表。
色彩世界：白色画纸、石墨标记、淡灰工作台、紫色选中胶带、青绿完成指示、暖红失败指示。只用紫色作为操作强调，成功/失败另有图标与文字。
标志性交互：**一个外观 × 多种发布规格**的输出计数。外观库用实际 renderer 生成中性缩略图；批量表每行显示原图名、尺寸和文字状态，避免同时解码整批输出缩略图增加内存压力。
拒绝三个默认：不加管理后台导航；不把所有功能堆成一屏小按钮；不把每个导出结果做成等权重营销卡片。

## Tokens

字体沿用自托管 DM Sans Variable；标题 26/600，面板标题 15/600，正文与控件 13/500，说明 11/400；关键尺寸和数量用 tabular-nums。4px 间距基准，面板 20–24px，控件间 8–12px，主要操作高 40px，图标按钮至少 32px，手机重要操作至少 40px。

`--studio-paper:#ffffff`，`--studio-desk:#f6f5f8`，`--studio-ink:#292431`，`--studio-pencil:#746a80`，`--studio-line:#e8e3ee`，`--studio-violet:#7756dc`，`--studio-violet-wash:#f2edfd`。错误使用有文字的暖红提示，成功使用勾选文字。可见文本目标 WCAG AA，字体/对比的自动化审计与人工核对见验证记录。

## 信息架构

`/` 仍是唯一工作空间；`/privacy` 解释新键、标注、批量内存与清除范围；`/api/health` 报 PicWiz v2。不增加登录、远程上传或空白占位路由。

桌面：品牌栏（PicWiz / 本地工作区 / Presets / Batch export / Help）；左画布与就近标注工具；右侧 Style / Annotate inspector；底部保留实际像素、尺寸、倍率、Copy image、Export PNG。外观库、批量面板、尺寸目录是带语义标题的 dialog。

手机：先画布，工具条允许换行或横向可滚动；下方 Style / Frame / Annotate 选项卡；图像选择状态不依赖鼠标悬停。批量面板改为每图一行的纵向结果表；输出选择先于开始按钮；导出栏保持可触达且不遮挡末尾控件。

## 各视图的完整状态

| 视图 | 主要 / 次要操作 | 状态与反馈 | 空 / 待处理 / 成功 / 可恢复失败 |
|---|---|---|---|
| 画布 | 添加图；替换、移除、缩放 | 源图名、实际输出像素、当前外观、保存状态 | 有示例与上传说明；解码进度；可编辑图；坏文件保留原图并说明格式 |
| 外观库 | 应用；保存、更新、重命名、删除、导入/导出 | Built-in / Yours 分组；真实中性缩略图；当前选择 | 六个 starter 始终可用；读文件提示；保存成功；重名/配额/无效 JSON 不部分提交 |
| 标注 | 添加箭头/矩形/文字；移动、改属性、删除、撤销重做 | 选中项、层列表、颜色与文字；截图坐标锚定 | 无标注说明与快捷入口；拖动临时态；保存成功；越界坐标/超数量拒绝 |
| 社交尺寸 | 选构图；倍率 | 场景、比例、基准尺寸与最终像素 | 当前项始终选中；选择即时预览；新尺寸确认；截图始终完整适配，绝不拉伸 |
| 批量导出 | Prepare ZIP → Download ZIP；取消、移除、重试失败 | N 图 × M 尺寸 = K PNG；共享风格快照；每项状态与总进度 | 无源图时选择文件；queued/running；全成功/部分成功；逐项失败与资源超限说明 |

## 标注交互细节

添加按钮直接插入可移动的默认对象，避免必须学会鼠标绘制。选中对象出现可见选中框（不导出）和属性。鼠标/触控拖动移动，矩形和箭头通过有标签的百分比字段调整大小；选中角点仅作位置提示；文字有明确输入框。方向键小步移动，Shift+方向键大步移动；Delete 删除；Ctrl/Cmd+Z / Shift+Z 只撤销/重做标注。所有操作有按钮替代快捷键；输入框内快捷键遵循原生编辑，不误删标注。

标注在截图内部裁切；边框和背景不接受标注。替换成功后重置标注和历史；失败保留图和标注。改外观/尺寸只改变构图，不改截图坐标。矩形不是可靠脱敏工具，UI 不宣传遮盖或自动脱敏。

## 预设和批次语义

外观是背景、留白、圆角、阴影、边框、外观主题；输出尺寸/倍率和内容标注不属于外观。中性缩略图用同一 renderer，绝不包含用户截图。更新已有外观需明确确认覆盖；删除有范围确认。

批量可包含当前图（带它自己的标注），其他添加图片不复制当前图标注。UI 在开始前明确说明。其他源文件仅在这个标签页中；刷新需重新添加。下载是单独一步，完成后不会意外触发多个浏览器下载。关闭进行中面板先取消；已编码的成功结果可在面板内下载，取消不自动下载，收尾后可显式打包已完成结果；关闭会丢弃这个会话批次。

## 尺寸语义

六项：Landscape / X composition 1600×900；Square 1080×1080；Portrait 1080×1350；Story 1080×1920；LinkedIn Page link image 1200×627；Pinterest standard image ad 1000×1500。通用三项不冒充已核验 Instagram 上传规范。平台标签对应研究中的场景，不承诺平台不会在其他入口裁切。所有尺寸都支持 1×/2×。

V2 的留白、圆角标为基准输出像素，倍率会成比例放大，预览按比例缩小。旧版本除 1600 宽外的已有样式会在迁移时换算留白/圆角，保留其构图占比；边框和阴影采用 V2 一致像素尺度，可能有小幅变化。

## 动效和无障碍

直接调整无入场动画；浮层只做短暂透明度变化，尊重 reduced-motion。原生 dialog 管理焦点，关闭回到触发器；状态使用 live region；控件有明确 label；不以颜色单独表达状态。主要动作位置一致。最终桌面、390×844、键盘与自动化结果保存在 validation.md。
