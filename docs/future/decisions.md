## 推荐推进顺序与依赖

1. **D1：Gallery。** 先验证用户能否更快完成发布素材；把模板和资产版本合同做好。
2. **D2：静态 3D 验证。** 先证明 GPU 回退、资源释放和 PNG 输出可信，再增加模型。
3. **D3：2D 视频验证。** 不依赖账号，也不必等 3D；3D 视频需等两条渲染／编码链都通过。
4. **D4：可选外观同步。** 可单独提前，但不会成为本地编辑、模板或视频的登录门槛。

这不是工期承诺。Gallery 的内容制作、3D 的模型授权和 GPU 调优、Video 的跨设备编码验证、Accounts 的安全与运维是各自主要工作量。先做范围有限的验证，比承诺未经测量的上线日期更有依据。

## 每个选择批准的边界

- D1A 不包含市场、用户模板上传、公共个人主页或团队库。模板参考和静态素材可以公开；用户截图不公开。
- D2A 不保证与真实 iPhone／MacBook 外观一致，不包含任意模型导入。具体授权与模型预算在使用素材前确认。
- D3A 不包含音轨、录屏输入、完整时间轴、批量视频或 4K／60fps 承诺。实际首发规格与格式探测、降级策略在 POC 后冻结；失败不自动切到云处理。
- D3B 需要另行确认隐私政策、云内容类别、区域、任务保留／删除、费用上限，以及供应商许可。不能把 D4 账号登录视作上传截图的同意。
- D4A/B/C 均不包含截图云存储或团队角色。建议的 Better Auth 是认证库，不是托管认证服务；需要明确维护责任人。Supabase 与 Clerk 仍是有意义的备选，不把 HttpOnly 不透明会话的设计偏好当作它们不安全的结论。区域、登录方式与月预算在建资源前确定；退出账号、删除账号与清空本地工作区分别确认范围。

账号推荐方案的示例公开底座为 $65/月：一个 [Supabase Pro 数据库](https://supabase.com/pricing) $25、[Resend Pro 邮件](https://resend.com/pricing?product=transactional) $20、一个 [Vercel Pro 开发者底座](https://vercel.com/pricing) $20；均为 2026-10-23 核验的税前口径。不是总成本：独立备份、维护、超量和税费另计；复用现有托管时新增服务底座约 $45/月。PITR 场景、100/1k/10k 月活假设与完整公式见 [账号费用分析](accounts.md#5-当前公开价格计量定义与预算)，不能据底座推断容量足够。
