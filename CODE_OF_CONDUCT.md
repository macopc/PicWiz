# Code of conduct

This project-specific code applies to PicWiz issues, pull requests, reviews and other project spaces.

- Treat people respectfully, including newcomers and people with different backgrounds or experience.
- Give specific, constructive feedback about the work. Accept reasonable correction and respect participation boundaries.
- Do not harass, threaten, discriminate, use sexualized abuse, repeatedly disrupt discussions or retaliate against someone who reports a concern.
- Do not publish another person's private information or screenshots without permission.

Maintainers may edit or remove harmful content, close or lock disruptive conversations, and restrict or block participation. The response should reflect the severity and repetition of the conduct; serious abuse may lead to immediate restriction.

## Reporting

For content that violates GitHub's policies, use the offending issue or comment's **⋯ → Report content → Report abuse to GitHub Support** flow. You can also report a user's profile through **Block or Report → Report abuse**. Follow [GitHub's official reporting instructions](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam), which also link its direct contact form if the in-product option is unavailable.

These reports go to GitHub Support. If GitHub offers **Report to repository admins**, that option can notify maintainers instead. Do not open a public issue containing a victim's private information, and do not assume a GitHub Support report has also reached this project's maintainers.

For software vulnerabilities, use [private security reporting](SECURITY.md).
